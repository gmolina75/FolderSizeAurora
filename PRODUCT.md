# Product Definition — Folder Size Aurora

## Overview

Folder Size Aurora is a Windows disk analyzer with size-limit monitoring and multi-channel alerts. The product name, UI language and brand constraints are defined below. No external UI libraries are used beyond Microsoft.Toolkit.Uwp.Notifications and Hardcodet.Wpf.TaskbarNotification.

## Brand Commitments

- Nombre: **Folder Size Aurora**. Established by the user.
- Idioma de la interfaz: español.
- Sin marcas ajenas: no se usan logotipos, colores ni activos de TreeSize, JAM Software ni ningún otro producto de referencia.

## Product Principles

1. **El número es la interfaz.** Cada fila debe poder leerse de un vistazo: nombre, tamaño, porcentaje, barras. La decoración que estorbe a la lectura se elimina.
2. **Densidad antes que aire.** Mucha información por pantalla; el usuario viene a comparar magnitudes, no a admirar el diseño.
3. **Ningún dato sin contexto.** Un tamaño sin su porcentaje respecto al total no sirve.
4. **Avisar sin martillear.** Enfriamiento, historial y resultado por canal: una alerta confiable vale más que diez alertas ignoradas.
5. **Fallar donde se ve.** Errores de permisos, rutas inaccesibles y fallos de envío se muestran en la interfaz, no se esconden en un log.

## Accessibility & Inclusion

Sin requisitos de accesibilidad específicos acordados con el usuario. Pendiente de confirmar: densidad alta puede chocar con texto pequeño, así que el tamaño de fuente base y el contraste deben verificarse en la interfaz final.
